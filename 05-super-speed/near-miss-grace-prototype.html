Rook Dispatch, proposal prototype

Near-Miss Grace Window

A responder reaches for the phone a second after an offer closes and finds it gone. Today the system counts that the same as a no. This proposal would log a late tap inside a short window as a near miss instead.

This is a proposal.

It changes the message the responder sees and the label in the handler log. It does not change scoring, offer order, or who gets offered jobs.

This version assumes Security approved full display of location and distance. That approval is not confirmed. Replace the sample values with real data only after sign-off.
